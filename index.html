🌟 Projet Phare / Flagship Project

POS Gebuco — Système de Point de Vente

PHP 8.3 | MySQL 8.0 | JavaScript | HTML/CSS

Contexte : Développement d'un POS complet pour une pharmacie en Haïti, avec gestion des ventes, de la caisse, des clients, des produits et de la fidélité.

Fonctionnalités clés :

  • Module de caisse (ouverture, fermeture, comptage, mouvements)
  • Module POS (4 modes de paiement, panier, lots, expiration)
  • Gestion des prix fournisseurs et conditionnements
  • Système de fidélité (points, échange cash, expiration)
  • Dashboard client (KPI, historique, profil)

Ce que j'ai appris : Conception de bases de données relationnelles complexes, architecture MVC, gestion des sessions et de la sécurité, résolution de bugs SQL avancés.

🔧 Scripts & Utilitaires

Requête SQL — Affichage des ventes par caisse

MySQL

Requête permettant de lister toutes les ventes effectuées par une caisse spécifique sur une période donnée, avec le total par mode de paiement.

Générateur de reçu PDF

PHP | FPDF

Script PHP qui génère un reçu de vente au format PDF, avec le logo de la pharmacie, les détails de la transaction et un QR code.

Ajout de logo sur une image

PHP (GD Library)

Script PHP qui prend une image (photo de produit) et y ajoute le logo de l'entreprise en filigrane.

Création d'image à partir de texte

PHP (GD Library)

Script qui génère une image avec un texte personnalisé (utile pour les promotions).

Formulaire électronique de collecte de données

HTML | PHP | MySQL

Formulaire pour la collecte de données sur le terrain, avec validation et envoi vers une base MySQL. Utilisé pour des enquêtes agricoles en Haïti.

Export Excel des ventes

PHP | PhpSpreadsheet

Script PHP qui exporte les données de vente vers un fichier Excel.
