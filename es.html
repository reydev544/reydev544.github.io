🌟 Proyecto Principal

POS Gebuco — Sistema de Punto de Venta

PHP 8.3 | MySQL 8.0 | JavaScript | HTML/CSS

Contexto: Desarrollo de un POS completo para una farmacia en Haití, con gestión de ventas, caja, clientes, productos y fidelidad.

Funcionalidades clave:

  • Módulo de Caja (apertura, cierre, conteo, movimientos)
  • Módulo POS (4 modos de pago, carrito, lotes, expiración)
  • Gestión de Precios de Proveedores y Empaques
  • Sistema de Fidelidad (puntos, cambio en efectivo, expiración)
  • Panel de Cliente (KPIs, historial, perfil)

Lo que aprendí: Diseño de bases de datos relacionales complejas, arquitectura MVC, gestión de sesiones y seguridad, resolución de bugs SQL avanzados.
